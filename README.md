# LostPetFinder

LostPetFinder is a web-based platform for reporting and managing lost and found pets.

The system allows users to register, add animal details, submit lost or found reports, search reports by location, and identify potential matches between lost and found pets.

## Features

- User registration
- Animal management
- Lost pet reporting
- Found pet reporting
- Search reports by location
- Lost and found pet matching
- Report resolution
- Admin management
- REST API
- Postman API testing
